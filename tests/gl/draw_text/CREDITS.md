# Test fixture provenance

`font_atlas.png` — a 16x6 grid of 10x16 glyph cells, ASCII 32-126, white
glyphs on a transparent background, generated for this test only (not
shipped as a language feature — `std/graphics` has no bundled default
font by design, see `Font.load`'s own doc comment).

Rendered via Python/Pillow using DejaVu Sans Mono, a free/open font
(Bitstream Vera License) shipped by the `fonts-dejavu` package on
Debian/Ubuntu — not written or hand-drawn for this project.
