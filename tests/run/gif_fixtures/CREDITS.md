# GIF fixtures

All generated for these tests with Python/Pillow; nothing downloaded.

- `long_anim.gif` — 480x360, 120 frames, a ball moving across a dark sky
  over green ground (frame i: ellipse at x = 3*i), 33ms per frame, saved
  with an adaptive palette. Used by `std_image_gif_stream.przp` and
  `tests/gl/animated_sprite_memory` for memory and streaming checks.
